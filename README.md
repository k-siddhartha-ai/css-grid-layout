# CSS Grid Layout – HTML & CSS Project

A practical front-end project demonstrating the power of **CSS Grid Layout** using HTML5 and CSS3. This project showcases a three-column grid structure, custom item positioning, row and column spanning, and interactive hover effects.

## 🌐 Live Demo

**[View CSS Grid Layout Project](https://css-grid-layout.vercel.app/)**

## 📌 Project Overview

This project demonstrates how to create and manage a grid-based webpage using CSS Grid. Six grid items are arranged in three columns with different positioning rules to understand how grid placement works.

Each grid item has a red background, yellow text, and a hover effect that changes its background to black and its text to yellow.

## ✨ Features

- Three-column CSS Grid layout.
- Six individual grid items.
- Custom row and column positioning.
- Grid item spanning across multiple columns.
- Grid item spanning across multiple rows.
- Interactive CSS hover effects.
- Custom background and text colors.
- Grid container border and spacing.
- Simple and beginner-friendly HTML structure.

## 🛠️ Technologies Used

- **HTML5** – Webpage structure.
- **CSS3** – Grid layout, styling, and hover effects.
- **CSS Grid** – Two-dimensional layout management.
- **GitHub** – Source code management.
- **Vercel** – Website deployment.

## 📚 CSS Concepts Practiced

| CSS Property | Purpose |
|---|---|
| `display: grid` | Creates a grid container |
| `grid-template-columns` | Defines three columns |
| `grid-template-rows` | Defines grid rows |
| `gap` | Adds spacing between grid items |
| `grid-column-start` | Defines the starting column |
| `grid-column-end` | Defines the ending column |
| `grid-row` | Controls row placement and spanning |
| `:hover` | Applies interactive hover styling |
| `background-color` | Changes background colors |
| `text-align` | Aligns item text |
